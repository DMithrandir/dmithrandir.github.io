2D 垂直切片

IN PROGRESS

二维是唯一能由个人把「所有算子与拓扑装配都做对」的完整闭环。解析闭式通道收口后，多项式通道已开启（线段×Bézier 落地），正向 Bézier×Bézier 与约束求解推进。

求交矩阵 · analytic-primitives + 多项式通道
#1Segment × Segment — 有理数行列式，共线重叠 / 端点接触 / 零长分类已落地
#2Segment × Circle/Arc — 判别式精确判号，弧段向量叉积过滤，切点单列已落地
#3Circle × Circle — 根轴法，外离/外切/相交/内切/内含/重合六分类已落地

§2

方法论四支柱

The 4-Pillar Methodology
PILLAR 01

预言机先于内核 + 变异自审

算子代码未动，黄金预测集先行。对验证台自身注入符号翻转、分母取错、守卫删除等变异，捕获率 100% 才允许准入。存活变异先查测试写虚，再查实现。

mutation kill rate = 24/24 · .pyc 复用坑已固化为回归断言
PILLAR 02

四层证据链

Tier 1 代数不变量 · Tier 2 解析真值 · Tier 3 外部多路对拍 · Tier 4 退化扰动平面。拒绝单一 assert_near；容差由用例自己声明。

Tier 3 未启用（缺 shapely/manifold3d，口径已写死：Shapely 只对折线）· Tier 5 重放待 P1
PILLAR 03

退化五族语料库

T 相切 · C 重合 · S sliver · I 自交/非流形 · N 数值抵消。每条带触发信号、修复模式与最小可执行用例，零死链，可被流水线按触发词检索。

degeneracy/index.json · 17 条 · 语料资产 > 算法代码
PILLAR 04

EntityRef 引用契约

确定性重放 + tombstone 显式失效 + split/merge 派生谱系。精确判定与容差语义分工明确：谓词回答符号，容差回答「算不算同一件事」，两者不可互替。

v0.2 · ADR-0004：确定性重放 ≠ 拓扑持久命名（TNP）
§3

明确的非目标

Explicit Non-Goals
  • 不训练端到端 Text/Image-to-CAD 大模型，只做底层几何验证器
  • 不复刻 OCCT 全量工业长尾；未建证据链前不堆 3D 特判
  • 不把容差当全局魔法常量；ToleranceContext 显式传递
  • P1 不自研符号图分解约束求解器（局部 LM + SVD 或 libslvs）
  • 不追 3D 变半径圆角 / 顶点混合、偏移抽壳自交裁剪
  • 不做直接建模（推拉面 + 删面自愈）
  • 不做 STEP 脏几何修复（Shape Healing）
  • 不做 GPU 隐式场 / SDF 路线

Field Notes
2026-11-09 · ORACLEBoehm 分母抄错：α 分母按记忆写成 U[i+p+1]−U[i]，几何不变性 oracle 当场判红。正确分母 U[i+p]−U[i] 已固化为解析反例与变异项。

2026-11-09 · RUNTIME.pyc 复用坑：等长变异同秒恢复，CPython (mtime,size) 校验复用变异后字节码——磁盘已恢复、行为仍坏。禁用字节码写入 + 清除 .pyc 已成硬纪律。
2026-11-20 · STATIC + AUDITSC005 首次实战拦截跨算子私有 import；变异审计证明 h²<0 防御守卫是不可达死代码（分类已在有理数上保证 h²≥0）——删除并注释推导。
