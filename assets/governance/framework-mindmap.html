    怎么修改

    全部内容在文件里的 DATA 常量中，是一棵纯 JSON 树，格式：

    { t:"标题", d:"说明", tag:"标签", k:"type", c:[ 子节点… ] }

    · t 标题（必填）
    · d 说明（可省）
    · tag 右侧小标签（可省）
    · k 层级配色：l0~l5（可省）
    · c 子节点数组（可省）

    改完存盘、刷新页面即可。点「导出 Markdown」可把当前树导出为大纲，便于回贴到文档里。

    快捷键：/ 搜索 · Esc 清空
