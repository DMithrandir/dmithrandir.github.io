## 这个实验台在做什么

目标是一个二维等权双峰高斯：$0.5\,\mathcal{N}((-2,0),\,0.75^2 I)+0.5\,\mathcal{N}((2,0),\,0.75^2 I)$。两个峰相距 4，单峰宽 0.75，和[第 5 篇](/mcmc/05-four-groups-and-a-sweep/)那个一维目标是同一把尺子，只是多了第二个坐标。

四组链跑在同一个目标上，每一步都记录接受率，并且用 $x_1$（两峰的连线方向）算积分自相关时间 $\tau$：

| 组 | 候选怎么生成 | 一句话 |
| :--- | :--- | :--- |
| **朴素 MH** | $x' = x + s$，$s\sim\mathcal{N}(0,I)$ | 基线，虚线 |
| **盲注噪声** | $x' = x + s + n$，$n\sim\mathcal{N}(0,\sigma_n^2 I)$ | 原论文的算法 2 |
| **方差匹配 MH** | $x' = x + s'$，$s'\sim\mathcal{N}(0,(1+\sigma_n^2)I)$ | 盲注链的等价写法 |
| **约束噪声** | $x' = x + s + n$，$n$ 满足 $|n|^2-2n\cdot s\le -2\sigma^2A(x)$ | 第 4 篇的 D 组 |
| **等步长 MH** | $x' = x + s''$，$\sigma$ 取约束链实测的步长 | 用来拆「选择」和「步长」 |

盲注链和它的对照组共用同一组基础跳跃 $s$（公共随机数），所以两条链的差别只来自噪声那一项。这不是为了制造巧合：噪声独立同分布时，卷积和调方差是同一个转移核，共用随机数只是把这件事实画得更清楚。

## 三个可以自己动手验证的结论

**一、盲注和方差匹配贴在一起。** 把 σ<sub>noise</sub> 从 0 拖到 2，盲注链的接受率一路下降，方差匹配链跟着下降；两条 τ 曲线也贴在一起，只在 5% 上下抖动。一维那边的参考数字是接受率差 0.001、$\tau$ 差 0.1（见下表）。

**二、约束链贴着等步长 MH。** 切到「等步长约束对照」，面板上会显示约束链自己量出来的步长 σ（默认噪声水平下约 1.46）。用这个 σ 跑的朴素 MH，τ 与约束链相差不到 6%。按第 4 篇的说法：约束噪声的收益可以完全由步长解释，不需要「选择」这个词。

**三、σ<sub>noise</sub>=0 时三组重合。** 此时 $n\equiv 0$，盲注就是朴素 MH，方差匹配的 $\sqrt{1+\sigma_n^2}$ 退回 1，约束的可行域塌成一点。三条线逐点重合——这也是实验台最便宜的一次自检。

## 参数与实现

- **求积**：$A(x)=\mathbb{E}_N[\ln\pi(x+N)-\ln\pi(x)]$ 用 8×8 高斯–埃尔米特张量积算，每个坐标 8 个节点。
- **拒绝采样**：约束组的 $n$ 最多试 32 次，全不满足就取 $n=0$（与 `experiments.py` 的 `constrained_mh` 一致）。默认噪声水平下回退占比约每 6 万步 2 次。
- **等步长**：切到约束模式时，先用 4000 步暖机量出约束链每个坐标的实测步长 sd，再用它作朴素 MH 的 σ。
- **$\tau$**：全历史的初始正序列估计（滞后上限 256），不是窗口估计。窗口估计在多峰目标上会被「这一窗里有几次跨峰」支配，抖动比信号大。
- **上限**：每轮跑到 10 万步停下，按「重跑」从头再来。

## 这个实验台不证明什么

- **二维不是证据。** 它把机制摆在台面上，但没有统计功效去支持任何「噪声有效/无效」的结论。要那个，得回到[第 5 篇](/mcmc/05-four-groups-and-a-sweep/)的配对种子、八个噪声水平与配对 Wilcoxon 检验。
- **约束组不是精确采样器。** 约束之后的提议对 $x$ 不再对称，严格说还需要一个 Hastings 校正项；实验台沿用原论文与第 5 篇 D 组的写法，不做校正。它比较的是几何与步长，不是不变性。
- **$\tau$ 有偏差。** 滞后截断、初始点、单链，三样都在。图上显示的是估计值，两条曲线重合说明的是「同一个量」，不是「这个量等于真值」。
- **单链 $\tau$ 有盲区。** 链困在一个峰里、却显示平稳，这件事 $\tau$ 看不出来，实验台也看不出来。[第 7 篇](/mcmc/07-reverse-noise/)的监控工具和近期那批耦合诊断针对的正是这个盲区，[拓展页](/mcmc/frontier/)里列了它们的入口。

## 一维的参考数字

同一套对照在[第 5 篇](/mcmc/05-four-groups-and-a-sweep/)的一维双峰目标上跑 6 万步，8 个种子（D 组 6 个），数字在 `results.json`：

| 组 | 接受率 | $\tau$（均值 ± sd） |
| :--- | ---: | ---: |
| A 朴素 MH，σ=1 | 0.649 | 70.9 ± 5.8 |
| B 盲注噪声，σ<sub>n</sub>=1 | 0.569 | 28.2 ± 1.1 |
| C 方差匹配 MH，σ=√2 | 0.568 | 28.1 ± 1.2 |
| D 约束噪声 | 0.550 | 24.7 ± 1.4 |

B 与 C 那两行就是整个系列的起点：**同一条曲线上的两个点**。噪声水平换掉，两个点会一起移，但不会分开。
