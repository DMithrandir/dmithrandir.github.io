[第 6 篇](/mcmc/06-what-i-got-wrong/)结尾留了一个问题：这条 2011–2019 的研究线，为什么在 2020 年之后被别的东西兑现了，而它自己停在了专利架上。

这一页是那个问题的正面回答。整理方式不是按时间，是按「它和单步提议微扰差在哪」：每个方向先给一句话的机制，再给一句「对本系列意味着什么」。

> 下面每条都指到原文。机制描述按 arXiv 摘要或原文核对过；论文集页只给链接、不引数字，免得把没读到的实验写成结论。

## 一、四条主干

| 方向 | 代表 | 与 N-MCMC 的差别 | 收敛与精度保障 |
| :--- | :--- | :--- | :--- |
| 去噪扩散采样 | [DDS](https://arxiv.org/abs/2302.13834)（Vargas, Grathwohl, Doucet，ICLR 2023） | 把目标正向扩散到高斯，再用路径空间 KL 变分学逆向 SDE 的漂移 | 路径空间变分界，指数积分器压离散误差 |
| 受控扩散 | [CMCD](https://arxiv.org/abs/2307.01050)（Vargas, Padhy, Blessing 等，2023） | 前向与后向动力学一起优化，连到薛定谔桥与 EM 的对应 | 路径空间散度作为可优化目标 |
| 连续时间 SMC | [SCLD](https://arxiv.org/abs/2412.07081)（Chen, Richter, Berner 等，2024）；[DDMC](https://arxiv.org/abs/2609.00279)（Hill，2026） | 把学到的漂移塞进 SMC 的转移核，或直接当全局 MH 提议 | 重采样 + 接受比里算前后向路径密度 |
| GPU 向量化 | [BlackJAX](https://arxiv.org/abs/2402.10797)（Cabezas, Corenflos, Lao 等，2024） | 函数式写法把控制流移出编译图，单卡跑几千条短链 | 配合多链诊断判断短链是否平稳 |

**扩散采样器**（DDS / CMCD）把「加噪」从一步的提议扰动，换成了整条路径上的传输问题。噪声不再是一个超参 $\sigma_n$，而是扩散时间表的一部分；要优化的对象从「接受率」变成了「路径空间上的散度」。

**连续时间 SMC** 补上了扩散采样的一个短板：学出来的漂移是近似的，采样结果就有偏差。DDMC 的做法是把前向与后向路径的密度都写进 MH 的接受比，于是近似误差只影响接受率，不影响不变分布——这和本系列反复强调的那件事是同一个要求：**先问这条链的不变分布是不是 $\pi$**。

**GPU 向量化**改的是另一件事：它让「调步长省 29% 步数」这种单链收益变成非关键瓶颈。当你可以同时跑 512 条短链时，单链的混合效率退居二线，诊断（这一批短链有没有跑够）反而成了瓶颈。

## 二、诊断：单链 $\tau$ 的两个替代品

实验台画的是单链 $\tau$。它在多峰目标上有一个众所周知的盲区：链困在一个峰里、看起来平稳，$\tau$ 与接受率都不报警。2025–2026 年有两条更硬的替代路线：

- **耦合 $f$-散度诊断**：[Corenflos & Dau (2025)](https://arxiv.org/abs/2510.07559) 用多条链之间的耦合权重协调（weight harmonization）造出可计算的 importance weights，于是 KL、$\chi^2$、总变差这些量可以直接监控，而不只是接受率这类代理指标。
- **多短链的 $\hat R$**：GPU 上跑几百条短链时，传统 $\hat R$ 的样本量不够。Nested $\hat R$（Margossian 等，[原文](https://sites.stat.columbia.edu/gelman/research/published/nestedRhat.pdf)）把子链分组嵌套计算，专门对付短采样期。

对实验台的意义很直接：它现在只有一条链、一个指标。把 $\tau$ 换成耦合 $f$-散度上界、把一条长链换成一屏短链，是下一步能立刻做的两件事（见第五节的 P1）。

## 三、LLM 侧：同一个不等式的另一个坐标系

[第 8 篇](/mcmc/08-test-time-scaling/)把「采样 $N$ 个再挑一个」映射到了同一条不等式上。2024–2026 年的 LLM 工作在两个方向上把这件事推成了工程：

**Best-of-N 的代价有一个明确的上界。** Beirami 等（[arXiv:2401.01879](https://arxiv.org/abs/2401.01879)，ICML 2025）处理的是文献里常被当成等式用的那个式子：$\mathrm{KL}(\pi_{\text{BoN}}\|\pi_{\text{ref}})=\log N-\frac{N-1}{N}$。他们证明它是错的——这个量其实只是实际 KL 的上界，并进一步讨论了它什么时候紧。配套的胜率上界是 $\frac{N}{N+1}$。两句话合起来就是本系列那句「收益是覆盖率、不是选择」的定量版：$N$ 翻倍，收益按 $1-1/N$ 的尾巴递减，分布偏移按 $\log N$ 增长。

**验证器有误差时，硬选最大值会放大漏洞。** [Inference-Time Reward Hacking in LLMs](https://proceedings.neurips.cc/paper_files/paper/2025/file/590a0cc0306c1c63e2d66a51a407718f-Paper-Conference.pdf)（NeurIPS 2025）与 [Aminian 等 (2025)](https://arxiv.org/abs/2507.05913) 把这件事做成理论：BoN 的效果取决于代理奖励模型的质量，而软化的版本（Soft Best-of-N，温度平滑重采样）可以被刻画。这正是第 8 篇「尾部不利时多采样会把准确率压到零」的现代版本。

**工程重心从「事后挑 N 个」挪到了「解码期 SMC」。** 三条证据：

- [Loula 等 (2025)](https://arxiv.org/abs/2504.13139)：把句法与语义约束写成 SMC 的势函数，生成中途按权重淘汰粒子；小模型在四个任务上超过 8 倍大的模型。
- [Markovic-Voronov 等 (2026)](https://arxiv.org/abs/2604.16453)：免训练奖励引导解码，把奖励势函数写进目标分布，用块级 SMC 采样，权重不动、只在推理期改分布。
- [Emara 等 (2026)](https://arxiv.org/abs/2604.15672)：投机解码里把「拒绝」换成「重加权重采样」，用一批草稿粒子维持目标分布。

这和第 8 篇的实验是同一个几何：多采样的收益来自覆盖面，选择的上限由验证器尾部决定；把选择搬到解码过程中间，只是把「N 次完整生成」的开销摊薄了，不等式本身没变。

## 四、几个学科里的落地

**计算化学。** [Dern 等 (2025)](https://arxiv.org/abs/2509.03726) 的 Energy-Weighted Flow Matching 只用能量函数评估训练连续归一化流，在 Lennard-Jones 团簇上做 Boltzmann 采样——这正是 Kosko 2019 年那个算例的现代替代。另一条线把平衡态下扩散模型的 score 直接当力场估计器，绕过显式的力标签（[NeurIPS 2025](https://proceedings.neurips.cc/paper_files/paper/2025/file/231be94eaf8dcbc49a95b256c9b6b8b5-Paper-Conference.pdf)）。

**格点场论。** [Yallup (2025)](https://arxiv.org/abs/2511.15196) 的结论值得单独提一句：在标量场论的基准问题上，GPU 加速的经典粒子方法（SMC 与嵌套采样）匹配甚至超过当前最好的神经采样器，而且顺带给出配分函数。这是「神经采样器 vs 经典 MCMC」争论里少见的一手对照。

**宇宙学。** [Staicova (2025)](https://doi.org/10.3390/universe11020068)（Universe 11(2):68）把 MH、HMC、切片采样、dynesty、PolyChord 放在同一批宇宙学后验上比了运行时间、内存、有效样本量与参数精度。它的用处不在结论，在于「同一批后验上到底谁贵」这件事有了可比的口径。

**金融与行为科学**这两个方向没有单独列条目：随机波动率与区制转换模型里 MCMC 与粒子滤波仍是主力估计手段，认知科学里 SMC 正在替代 MH（多峰后验之外，它还几乎零成本地给出边际似然，可直接算贝叶斯因子）。两处都不需要新的理论，需要的是工程实现。

## 五、这条线上还缺什么

按优先级排，和[专题页](/mcmc/)上的状态表是同一张：

| 优先级 | 内容 | 状态 |
| :--- | :--- | :--- |
| **P0** | 第 3、4 篇的交互实验台；专题页的现代基线表；这一页 | ✅ 已上线 |
| **P1** | 用 JAX / BlackJAX 补 NUTS 与 ChEES 风格的并行短链对照；把实验台的单链 $\tau$ 换成多链诊断（耦合 $f$-散度或 Nested $\hat R$） | ⬜ 计划 |
| **P2** | 把第 8 篇的「多采样失效边界」做成 Python 模块：输入参考分布、验证器噪声与单次采样成本，输出 $N^*$ 与熔断阈值 | ⬜ 计划 |

P1 的第一件事是把实验台的链变成可比的重复：现在面板上的几条链共用随机数，能验证「盲注 ≡ 方差匹配」，不能验证「这条链收敛了」——后者要的是一批独立链上的诊断，不是更长的单链。
