2020 年我交上去的那篇毕业论文没有实验。定理是读来的，机制是信来的，数字一个也没有。六年后的这个系列，前半程在拆机制，这一篇把缺的实验补齐：一个双峰目标，四个采样器，两个语境，加一次八水平的噪声扫描。代码是 `experiments_paper.py`，原始数字在 `results.json`，下面每个数都能回到那里。

## 目标与四组

目标取 \(0.5\,\mathcal{N}(-2,0.75^2)+0.5\,\mathcal{N}(2,0.75^2)\)：两个峰相距 4，单峰宽 0.75，从一个峰到另一个必须穿过中间的低密度区。选一维不是图省事——它让 KL 能数值算，也让约束里的 \(A(x_t)\) 能逐点积分；代价是全部结论都带一个「一维」的限定。

四组对照如下，提议的基础尺度都是 σ=1：

| 组 | 提议 | 一句话 |
|---|---|---|
| A | 朴素 MH，σ=1 | 基线，与 σ_n 无关 |
| B | 盲注噪声：\(x+s+n\)，\(s\sim\mathcal{N}(0,1)\)，\(n\sim\mathcal{N}(0,\sigma_n^2)\) | 论文的算法 2；接受只用 π 比值 |
| C | 方差匹配：朴素 MH，σ=√(1+σ_n²) | 03 的等价性要求的对照 |
| D | 约束噪声：\(n\) 按 \(n^2-2sn\le b\) 拒绝采样，\(b=-2\sigma^2A(x_t)\) | 每步一次 48 点 Gauss–Hermite 积分 |

D 比前三组贵一个量级：每一步要算一次 \(A\)（48 点积分），再最多试 32 次拒绝采样。这既是它只跑 60 个种子的原因，也是它很难进产品的原因之一——机制上说得通，工程上太贵。

四组共用同一条接受规则：\(\alpha=\min\{1,\ \pi(y)/\pi(x_t)\}\)，不含 Hastings 修正。这不是省略——Franzke–Kosko 的算法就是这样写的，03 的等价性也只在这个前提下成立；换成完整的 MH 比率，B 与 C 的转移核立刻不同。D 的 \(A\) 用基础噪声律 \(\mathcal{N}(0,\sigma_n^2)\) 积分，不用被约束后的分布；也就是说约束是一个「提议机制」，不进入接受率。照原样实现，因为要检验的就是原算法的行为；至于这个不对称提议的平稳分布是不是 π，02 已经说明原始文献没有处理。

## 两个语境，别混着用

E1 测混合：初始点 \(x_0=0\)（两峰之间的势垒上），跑 60000 步，A/B/C 各 8 个种子、D 6 个；指标是接受率、积分自相关时间 \(\tau_{\mathrm{int}}\)、运行边际与目标的 KL（28 个对数间隔的检查点）。

E3 测燃烧期：初始点 \(x_0=-5\)（左峰远侧），记录首次到达 \(x>1.25\) 的步数，上限 20000 步；盲注与方差匹配各 200 个种子、约束 60 个。

这两个语境测的不是同一件事。KL 与 τ 问的是「有没有逼近并停留在 π」，首达时间问的是「多久跨过去」；一条链可以很快跨过去又跑回来，也可以在目标附近磨很久。原论文报的是「达到阈值步数」，所以它的证据其实只落在燃烧期（优化）语境里。我从不在两个语境之间互推，只在同一语境里比组间。

阈值取 1.25 而不是 2.0：只要越过势垒、进入右峰的上升段就够了，不要求链在右峰里停稳。这是首达与 E1 不能互推的另一半原因。

## E1：四组，六万步

| 组 | 接受率 | τ_int |
|---|---|---|
| A 朴素 MH，σ=1 | 0.649 | 70.9 ± 5.8 |
| B 盲注噪声，σ_n=1 | 0.569 | 28.2 ± 1.1 |
| C 方差匹配，σ=√2 | 0.568 | 28.1 ± 1.2 |
| D 约束噪声 | 0.550 | 24.7 ± 1.4 |

（8/8/8/6 个种子 × 60000 步；± 是种子间标准差。）

B 与 C 的接受率差 0.001、τ 差 0.1，和 03 的严格等价一致——那不是「差不多」，是同一个转移核的两条样本路径。D 的 τ 比它们低（24.7 对 28.2 / 28.1），接受率也更低（0.550 对 0.569 / 0.568）。A 的自相关时间是 D 的近三倍，接受率却更高：低接受率配上低自相关时间，最自然的解释就是每次接受走得更远。这是步长故事的第一个信号，04 把它做成了正面证据。不过 D 与 B/C 的 τ 差只有三到四步，而 D 的种子只有 6 个（±1.4）：方向可信，量级别当铁律。

## E3：八个噪声水平

| σ_n | B 盲注 | C 方差匹配 | D 约束 |
|---|---|---|---|
| 0.25 | 92.0 ± 5.5 | 91.9 ± 6.7 | 69.8 ± 7.7 |
| 0.50 | 70.1 ± 4.2 | 70.1 ± 4.3 | 49.9 ± 4.7 |
| 0.75 | 48.9 ± 2.8 | 53.8 ± 3.0 | 40.3 ± 4.1 |
| 1.00 | 34.1 ± 2.0 | 38.8 ± 2.3 | 30.4 ± 2.9 |
| 1.50 | 21.3 ± 1.1 | 20.5 ± 1.3 | 21.2 ± 2.1 |
| 2.00 | 13.7 ± 0.8 | 16.0 ± 1.0 | 17.2 ± 1.6 |
| 2.50 | 10.9 ± 0.7 | 11.8 ± 0.7 | 14.5 ± 1.3 |
| 3.00 | 9.7 ± 0.6 | 9.5 ± 0.6 | 12.6 ± 1.1 |

（均值 ± 标准误；盲注/方差匹配 200 个种子，约束 60 个。从 \(x_0=-5\) 到 \(x>1.25\)，上限 20000 步。）网格故意在 0.25–1 之间排得密，因为 D 的收益集中在那一段；2 以上只放了 2.0、2.5、3.0 三个点，够看出反超的方向。

读这张表要守住基线。σ_n≤1 的四个水平上 D 领先：0.25 时 69.8 对 92.0 / 91.9，0.5 时 49.9 对 70.1 / 70.1，0.75 时 40.3 对 48.9 / 53.8，1.0 时 30.4 对 34.1 / 38.8。峰值在 σ_n=0.5：相对 B 和 C 都少 29% 的步数。σ_n=1.5 时 D 与 B 打平（21.2 对 21.3）、落后 C（20.5）；σ_n≥2 之后落后两者。

这里必须把口径写死：−29% 是**相对方差匹配（或盲注）基线的步数减少**，不是「噪声加速 29%」。它衡量的是「约束组比一个方差相当的普通提议少走多少步」，而不是噪声本身贡献了什么。

为什么峰值不在更小的 σ_n？σ_n→0 时，被接受的噪声本身趋于 0，D 与 C 一起退化成 σ=1 的同一个朴素 MH，收益必然趋于零；曲线从 0 升上来，到 0.5 附近见顶，再被基线的线性增长压下去。σ_n 再大，D 的步长增长慢，交叉点落在 1 与 2 之间——表里 1.5 那一行，D 与 B 的误差棒已经叠在一起。

还有一格是原表没有的：A。A 是论文自己在 E1 里命名并使用的基线，σ=1，与 σ_n 无关；我补跑两次，92.5 与 87.4 步，约 87–92。把它放进来，D 在八个水平上全部远优于 A（最差的一格 69.8，仍是 A 的七成多）。原文的表 2 只列 B 和 C，于是 σ_n≥2 那一行看上去像绝对失败；其实「转劣」只相对于两个越来越激进的基线成立——σ_n 越大，B/C 的单步越占便宜，而 D 的步长被约束钉在一条缓慢增长的轨道上（04 有实测：1.142 / 1.264 / 1.492 / 1.918 / 2.341，对应 σ_n=0.25/0.5/1/2/3）。倒 U 形不是「选择失效」，是两条步长曲线交叉。

## 三处该说清楚的弱点

**第一，种子不配对，样本量也不齐。** E1 是 8/8/8/6，E3 是 200/200/60；B/C 用 `default_rng(100000+seed)`，D 用 `default_rng(300000+seed)`——两套随机数流不同，样本量差三倍多。首达时间对种子很敏感，一个配对设计（同种子、同随机数流）本可以用更少的样本取得更高的功效，我当时没做。表里的 ± 是组内标准误，不包含实现间波动，所以 E3 表里的数应当读作「一次实现的点估计」，不是可复现的物理常数。

**第二，表里缺基线 A。** 这一条比第一条更该改：A 是论文自己命名并使用的基线，却从 E3 的表里消失了，于是读者看到的「转劣」被基线选择放大了。补上 A 之后结论更强，不是更弱——D 在八个水平上都优于 A，唯一变差的是 D 与 B/C 的比较。

**第三，配对检验没有做，我补了。** 用 200 个配对种子做 B 对 C 的 Wilcoxon 符号秩检验：σ_n=0.25 时 p=0.906、σ_n=1.0 时 p=0.582、σ_n=2.0 时 p=0.970。三个水平都不能拒绝「两组没有系统差异」；三次检验的 p 值都远离 0.05，不做多重比较校正也不影响结论。这是论文本该做而没做的检验；结论与 03 的定理一致，但定理比检验强得多——转移核相等不需要 p 值。D 与 C 的配对检验我没有做：D 只有 60 个种子，随机数流也不同，硬配对的意义有限，那一组对照交给 04 的等步长实验。

## 独立复现：最大差 12%，排序没变

重跑不是把原代码再执行一遍。我重写了采样器，换种子基底，重新实现四个组；E1 的 A/B/C 仍是 8 个种子 × 60000 步。「换种子基底」的意思是不沿用 100000+seed 与 300000+seed 这两段流，另起一批偏移，让链的随机路径整体换一组。

结果：E1 的接受率是 0.651 / 0.570 / 0.569（原 0.649 / 0.569 / 0.568），τ 是 72.8 / 31.0 / 29.1（原 70.9 / 28.2 / 28.1），τ 略高一点，是估计器差异——「首个非正自相关截断 + 0.5」对双峰链系统性偏低，两边都按同一规则算，所以组间比较仍可用，跨论文比较不行。E3 那边，与原始数字最大的一处差是 12%，出现在 σ_n=0.25 那一行。

12% 与组内标准误同量级，这本身就是一条信息：表里的 ± 低估了实际不确定性。但排序是稳的——B≈C；D 在 σ_n≤1 最优；σ_n≥2 相对 C 转劣；D 始终优于 A。04 的机制结论和 06 的复盘都不依赖具体小数，依赖的是排序和几何。

## 数字没问题，解释有问题

把两组实验放在一起，我的结论是：这些数字本身没问题。表 1 的每一格都能从 `results.json` 逐位复现；E3 的排序在我的独立复现里没有变；B≡C 有定理也有数字；D 在两个语境里都排在前面。

问题出在解释上，而且分布在三层：把「选择」当成机制（04 拆了）；把逐点的恒等式当成链平均的排序判据（04 也拆了）；把基线选窄到只剩 B 和 C、把不配对的种子当成可接受的默认（这一篇补了）。再往上一层，是 06 要清算的三处错误与一个用错的词。

这套结论的适用范围也要说清楚：等权双峰、一维、高斯跳跃、σ=1 的基础尺度。换到多峰、高维或非高斯提议，表里的数字一个都不能搬；能搬的是方法——先做等步长对照，再谈机制。

所以这一篇的任务到此为止：把数字摆清楚，把弱点写在明处。形状由 04 解释，错误由 06 收尾。
